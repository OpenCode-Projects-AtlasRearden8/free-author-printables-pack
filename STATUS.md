# Status - Author Book-Day Printables Pack

## What was built

A complete, local-only printable pack for book days: 7 printable sheets as
HTML/CSS sources plus a friendly usage guide per sheet, rendered to
unbranded PDFs by one build script.

- **Sheets (`sources/*.html`, shared `sources/css/sheet.css`):**
  1. Launch-Week Countdown Calendar (7-day grid, pre-launch focus per day)
  2. Launch-Day Checklist (morning/midday/afternoon/evening blocks)
  3. Bookmark Templates (2 per page, fill-in blanks, cut lines)
  4. Thank-You Card Templates (3 quarter-fold cards per page)
  5. Series Bible One-Pager (books, cast, places, timeline rules)
  6. Signing & Market Day Sales Log (tally rows + totals; no customer data)
  7. Review Request Postcards (2 per page; buyer fills in personal fields)
- **Usage guides:** an auto-rendered 1-page "how to use" PDF per sheet in
  `printables/usage/` (generated from a friendly template in `build.py`).
- **Build:** `build.py` uses WeasyPrint; US Letter, 0.5 in margins,
  ink-friendly design; output is unbranded (no company/author names on the
  printables themselves).
- **Tests:** `tests/test_build.py` (pytest) runs the build in a temp copy of
  the repo and checks: all 14 PDFs exist, valid `%PDF` header + pages +
  text layer via pypdf, US Letter MediaBox, sane file sizes, no secrets or
  emails in sources, sheets contain no brand tokens, every sheet links the
  shared CSS.
- README.md (crediting **Asdale Dynamics, LLC**) and MIT `LICENSE` with the
  exact copyright line `Copyright (c) 2026 Asdale Dynamics, LLC`.

## How to run

```
python3 -m venv optional ...  # not required; system pip works
pip install weasyprint pytest pypdf
python3 build.py              # builds printables/ and printables/usage/
python3 -m pytest tests/ -q   # verifies every sheet builds a valid PDF
```

Everything runs locally: no network calls, no accounts, no telemetry, no
secrets or personal data in any file.

## Verification results

- `python3 build.py` -> builds 14 PDFs (7 sheets + 7 usage guides), exit 0.
- `python3 -m pytest tests/ -q` -> **20 passed, 0 failed.**
- Manual spot checks: PDFs open in standard readers, text layer intact,
  letter-size boxes confirmed programmatically.

## Known gaps

- Usage guides are generated by the build script rather than hand-authored
  HTML files; edit the `USAGE_TEMPLATE` in `build.py` to change their copy.
- WeasyPrint text-layer extraction can merge adjacent columns in the sales
  log header, but visually the tables render correctly; only the presence
  of a text layer is tested.
- Postcard and card templates fill in by hand/cut; a full-bleed duplex
  (front/back) variant is not included.
- No A4 variant; sheets are US Letter only (print "Actual size" to scale).
